# Лабораторная работа №1

## Цель работы

Изучить принципы представления цвета в моделях **RGB**, **XYZ** и **HSV**, а также методы преобразования цветовых координат между данными моделями.  
Разработать приложение на языке **C#**, позволяющее интерактивно задавать цвет и автоматически отображать его параметры в нескольких цветовых моделях.

## Задачи

- Реализовать ввод цветовых значений вручную и с помощью элементов управления интерфейса.
- Обеспечить автоматический пересчёт параметров **RGB**, **XYZ** и **HSV** при изменении любой цветовой компоненты.
- Реализовать выбор стандарта освещения **D65**, **D50** или **E** и динамический расчёт матрицы перехода в модель **XYZ**.
- Реализовать обработку выхода полученных значений за допустимый диапазон с использованием стратегии **Clipping** (обрезание).
- Создать понятный графический интерфейс и разделить программную часть на независимые слои **Model**, **View** и **ViewModel**.
- Проверить корректность основных математических преобразований с помощью автоматических тестов.

## Инструментарий

В процессе выполнения лабораторной работы использовались:

- язык программирования **C#**;
- платформа **.NET 8**;
- технология **WPF** для разработки графического интерфейса;
- среда разработки **Microsoft Visual Studio** для создания проекта и его отладки.

Математические преобразования реализованы самостоятельно, без применения сторонних библиотек для конвертации цветов.

## Ход работы

1. Сначала был разработан графический интерфейс приложения.  
   Для каждой цветовой модели предусмотрены поля для точного ввода значений и элементы **Slider** для их интерактивного изменения.  
   Также реализован выбор цвета из стандартной системной палитры.

2. Основная математическая часть программы была вынесена в отдельные классы.  
   Для преобразования **RGB → XYZ** выполняется нормализация компонент, обратное гамма-преобразование и умножение на матрицу перехода.  
   В зависимости от выбранного источника освещения **D65**, **D50** или **E** матрица рассчитывается автоматически.  
   Обратное преобразование из **XYZ → RGB** выполняется с использованием обратной матрицы.

3. Для модели **HSV** реализованы прямые преобразования **RGB → HSV** и **HSV → RGB**.  
   Значения оттенка задаются в диапазоне от **0 до 360 градусов**, а насыщенность и яркость — в процентах.

4. При получении **RGB**-значений, выходящих за допустимый диапазон, применяется стратегия **Clipping**:
   - значения меньше **0** заменяются на **0**;
   - значения больше **255** — на **255**.

   Пользователь получает соответствующее предупреждение в интерфейсе.

5. Для удобства сопровождения программа разделена на несколько частей:
   - **Model** содержит математические операции;
   - **View** отвечает за графический интерфейс;
   - **ViewModel** связывает интерфейс с вычислительной частью программы.

   Дополнительно были созданы автоматические тесты для проверки результатов цветовых преобразований.

## Выводы

В ходе выполнения лабораторной работы было разработано приложение для работы с цветовыми моделями **RGB**, **XYZ** и **HSV**.  
Были реализованы:

- ручной ввод и интерактивное изменение компонентов цвета;
- автоматический пересчёт между моделями;
- выбор стандартов освещения **D65**, **D50** и **E**;
- обработка выхода значений за допустимый диапазон с помощью **Clipping**.

В процессе работы были закреплены знания о принципах представления цвета и матричных преобразованиях, а также получены практические навыки разработки приложений на **C#** и **WPF**.  
Разделение программы на **Model**, **View** и **ViewModel** позволило отделить математические расчёты от интерфейса и упростить дальнейшее тестирование и изменение программы.
