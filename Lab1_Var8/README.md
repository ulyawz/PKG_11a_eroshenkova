# Лабораторная работа №1

## Цель работы

Целью работы является изучение принципов представления цвета в моделях RGB, XYZ и HSV, методов преобразования цветовых координат между данными моделями, а также разработка интерактивного приложения на языке C#, позволяющего задавать цвет и автоматически отображать его параметры в нескольких цветовых моделях.

## Задачи

- Реализовать ввод цветовых значений вручную и с помощью элементов управления интерфейса.
- Обеспечить автоматический пересчёт значений RGB, XYZ и HSV при изменении любой цветовой компоненты.
- Реализовать выбор стандартного источника освещения D65, D50 или E и автоматический расчёт матрицы преобразования в модель XYZ.
- Реализовать обработку выхода полученных RGB-значений за допустимый диапазон с использованием стратегии Clipping.
- Разделить программную часть на Model, View и ViewModel для отделения математических расчётов от графического интерфейса.
- Проверить корректность основных математических преобразований с помощью автоматических тестов.

## Инструментарий

При разработке приложения использовались язык программирования C#, платформа .NET 8 и технология WPF для создания графического интерфейса. Для разработки, сборки и отладки проекта использовалась среда Microsoft Visual Studio. Математические преобразования реализованы самостоятельно без применения сторонних библиотек для конвертации цветов.

## Ход работы

В ходе работы был разработан графический интерфейс приложения. Для моделей RGB, XYZ и HSV предусмотрены поля для точного числового ввода и элементы Slider для интерактивного изменения компонентов цвета. Также реализован выбор цвета с помощью стандартной системной палитры. При изменении любой координаты значения остальных моделей автоматически пересчитываются.

Основная математическая часть программы была вынесена в отдельные классы. Для преобразования RGB в XYZ выполняется нормализация компонент, обратное гамма-преобразование и умножение на матрицу преобразования. В зависимости от выбранного стандарта освещения D65, D50 или E матрица рассчитывается автоматически. Обратное преобразование из XYZ в RGB выполняется с использованием обратной матрицы.

Для модели HSV реализованы прямые преобразования RGB → HSV и HSV → RGB. Оттенок задаётся в диапазоне от 0 до 360 градусов, а насыщенность и яркость — в процентах. При изменении значений HSV соответствующий цвет автоматически пересчитывается в RGB и XYZ.

Для обработки некорректных RGB-значений реализована проверка выхода за допустимый диапазон 0–255. При выходе за границы применяется стратегия Clipping: значения меньше 0 заменяются на 0, а значения больше 255 — на 255. Пользователь получает предупреждение о выходе за цветовой охват.

Структура приложения разделена по принципу Model–View–ViewModel. Model отвечает за хранение текущих цветовых значений и выполнение математических преобразований, View отвечает за отображение данных и элементы управления, а ViewModel связывает интерфейс с моделью. Дополнительно были созданы автоматические тесты для проверки результатов цветовых преобразований.

## Выводы

В ходе выполнения лабораторной работы было разработано приложение для работы с цветовыми моделями RGB, XYZ и HSV. Были реализованы ручной ввод и интерактивное изменение компонентов цвета, автоматический пересчёт между моделями, выбор стандартов освещения D65, D50 и E, а также обработка выхода значений за допустимый диапазон с помощью стратегии Clipping.

В процессе работы были закреплены знания о принципах представления цвета, работе с матрицами и преобразовании цветовых координат. Были получены практические навыки разработки приложений на C# и WPF. Разделение программы на Model, View и ViewModel позволило отделить математические расчёты от интерфейса и упростить тестирование и дальнейшее сопровождение программы.
