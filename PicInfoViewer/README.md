# Лабораторная работа №2

## Цель работы

Целью работы является изучение принципов чтения и хранения характеристик графических файлов различных форматов, а также разработка приложения на языке C#, позволяющего сканировать папки, определять параметры изображений и отображать полученную информацию в графическом интерфейсе.

## Задачи

- Реализовать выбор папки для сканирования и поиск изображений во вложенных каталогах.
- Обеспечить обработку графических файлов форматов JPEG, PNG, GIF, BMP, TIFF и PCX.
- Реализовать определение размеров изображений, разрешения в DPI, глубины цвета и параметров сжатия.
- Разработать отдельные парсеры для чтения характеристик поддерживаемых форматов.
- Реализовать отображение результатов в таблице и поиск файлов по имени.
- Добавить предварительный просмотр выбранного изображения и поддержку анимации GIF.
- Реализовать отображение прогресса сканирования и возможность отмены обработки файлов.
- Использовать параллельную обработку для ускорения чтения характеристик изображений.

## Инструментарий

При разработке приложения использовались язык программирования C#, платформа .NET 8 и технология WPF для создания графического интерфейса. Для разработки, сборки и отладки проекта использовалась среда Microsoft Visual Studio. Для чтения характеристик изображений реализованы собственные методы обработки форматов без применения сторонних библиотек для извлечения метаданных.

## Ход работы

В ходе работы был разработан графический интерфейс приложения, позволяющий выбирать папку для сканирования или перетаскивать её в окно программы. Предусмотрена возможность поиска изображений во вложенных каталогах. Поддерживаются форматы JPEG, PNG, GIF, BMP, TIFF и PCX.

Для чтения характеристик изображений был реализован класс ImageReader. Метод Read определяет формат файла и вызывает соответствующий парсер. Для каждого формата предусмотрен отдельный метод, который считывает необходимые данные из файла. Полученные характеристики сохраняются в объекте ImageRow, содержащем имя и формат файла, размеры изображения, разрешение, глубину цвета, информацию о сжатии и полный путь к файлу.

Для чтения данных используются файловые потоки и операции обработки байтов. В зависимости от формата изображения парсеры извлекают необходимые значения из заголовков и других структур файла. Для определения числовых значений учитывается порядок расположения байтов, предусмотренный форматом.

Результаты обработки отображаются в таблице. Реализован поиск файлов по имени, а при выборе строки отображается предварительный просмотр соответствующего изображения. Для GIF дополнительно предусмотрена поддержка анимации. Если формат не поддерживается средствами отображения WPF, приложение сообщает о невозможности предварительного просмотра.

Для повышения производительности реализована параллельная обработка файлов с ограничением количества одновременно выполняемых операций. Во время сканирования отображается количество обработанных файлов и общее время выполнения. Также предусмотрена возможность отмены обработки и обработка возникающих ошибок.

## Выводы

В ходе выполнения лабораторной работы было разработано приложение для чтения и отображения характеристик графических файлов. Были реализованы обработка нескольких форматов изображений, определение их основных параметров, поиск по имени, предварительный просмотр и отображение прогресса сканирования.

В процессе работы были закреплены знания о структуре графических файлов, организации файловых потоков и обработке бинарных данных. Были получены практические навыки разработки приложений на C# и WPF, работы с файловой системой, асинхронного выполнения задач и параллельной обработки данных.
